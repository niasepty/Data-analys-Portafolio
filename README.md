# Data Analyst Portfolio

Repositori ini berisi kumpulan proyek latihan dalam proses belajar analisis data, mencakup pembersihan data, penggabungan data antar tabel, hingga peringkasan dan visualisasi data.

## Daftar Proyek

| No | Proyek | Deskripsi Singkat | Tools |
|---|---|---|---|
| 01 | [Data Cleaning, VLOOKUP, dan Pivot Table](./01-data-cleaning-vlookup-pivot) | Membersihkan data transaksi dari duplikasi, mencari data antar tabel dengan VLOOKUP, dan meringkas data dengan Pivot Table | Microsoft Excel |

## Tentang

Portofolio ini disusun secara bertahap seiring proses belajar. Setiap proyek disimpan dalam folder terpisah, lengkap dengan berkas kerja dan penjelasan proses di dalamnya.
